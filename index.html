THE PROBLEM & INNOVATION

Bridging the Gap from Raw CV to Municipal Action

Manual road inspections are slow, hazardous, non-standardized, and lack continuous geospatial tracking. Here is how our system revolutionizes highway infrastructure monitoring.

Traditional Inspection Deficiencies

Highway authorities rely on manual physical walk-throughs or manual photographic logs. They are labor-intensive, error-prone, subjective to individual inspectors, and leave thousands of road kilometers unmonitored for months.

  • High hazard risks for road surveyors
  • Lack of exact geo-synchronized coordinates
  • Delayed municipal response times

The Computer Vision Research Gap

Existing academic research trains deep neural networks on isolated benchmark image sets but stops at standard mAP metrics. Bounding boxes without geographic coordinates are useless to municipal road crews on the field.

  • No geospatial coordinate fusion
  • Detection confidence conflated with damage severity
  • Absence of lightweight, deployable visual dashboards

Our Integrated Solution

A cohesive edge-to-cloud architecture combining lightweight vehicle dashcams, fine-tuned YOLO object detection, NMEA GPS geotagging, deduplication filters, and a GIS-enabled decision support dashboard.

  • Sub-meter defect localization with GPS
  • Visual severity estimation (Low, Medium, High)
  • Automated route clustering & repair dispatch export

ENGINEERING PIPELINE

System Architecture & Processing Flow

How raw dashcam video turns into actionable spatial maintenance data through 5 coordinated layers.

01

Data Acquisition

Vehicle-mounted dashcam or smartphone capturing 1080p road video stream synchronized with GNSS receiver logging NMEA coordinate sentences at 1-5Hz.

02

AI Neural Inference

Ultralytics YOLO single-stage detector extracts bounding boxes, class classification probabilities, and confidence scores at 35+ FPS.

03

Spatial Fusion & Dedup

Detection frames are timestamp-matched with the nearest spatial coordinates. Temporal buffer filters repeated frames of the same road defect.

04

Severity Categorization

Calculates relative pavement surface occupancy, defect class weight (potholes prioritized over hairline cracks), and assigns Low, Medium, or High severity.

05

GIS Visualization & APIs

FastAPI backend stores records into SQLite/PostGIS and streams GeoJSON data to our interactive Leaflet dashboard for municipal road crews.

COMPREHENSIVE TECHNICAL ANALYSIS

Deep-Dive: How Every Component Functions

An in-depth explanation of the computer vision algorithms, dataset taxonomy, and geospatial fusion logic formulated in the project report.

1. RDD2022 Benchmark Dataset & Annotation Taxonomy

The system leverages the multi-national RDD2022 (Road Damage Dataset) introduced by Arya, Maeda et al., featuring over 47,000 images and 55,000+ annotations collected across Japan, India, the Czech Republic, Norway, USA, and China. Unlike single-country datasets, this ensures our detector generalizes across varying pavement compositions, dirt accumulations, monsoon weathering, and camera angles.

Class Code Defect Category Physical Manifestation Safety / Engineering Significance
D00 Longitudinal Crack Parallel to the centerline of pavement along wheel tracks or construction joints. Allows moisture penetration into sub-base; escalates to structural failure if untreated.
D10 Transverse Crack Perpendicular to the centerline; caused by thermal shrinkage or base contraction. Causes vehicle ride bumpiness; promotes water pooling along cross sections.
D20 Alligator Crack Interconnected network of fatigue fractures resembling reptile skin. Severe structural fatigue failure of the load-carrying asphalt pavement.
D40 Pothole Bowl-shaped road depression resulting from water ingress and traffic impact. Critical hazard causing tire blowouts, vehicle accidents, and motorcyclist fatalities.
2. YOLO Real-Time Single-Stage Detection Pipeline

Traditional two-stage detectors (like Faster R-CNN) yield high precision but struggle with high-frame-rate processing on edge devices. We deploy a single-stage YOLO (You Only Look Once) architecture. YOLO frames object detection as a regression problem directly from full-image pixels to bounding box coordinates and class probabilities in a single forward pass.

  • Backbone: CSPDarknet feature extractor with PANet/BiFPN neck providing multi-scale feature fusion for detecting tiny hairline cracks alongside expansive potholes.
  • Loss Functions: Complete Intersection over Union (CIoU) loss for precise box regression, coupled with Binary Cross-Entropy (BCE) for multi-label classification.
  • Non-Maximum Suppression (NMS): Filters redundant overlapping candidate boxes using IoU thresholding (default 0.50).
3. Spatio-Temporal GPS Coordinate Fusion & Deduplication

When a vehicle moves at 40 km/h (~11.1 m/s), a single pothole is visible across 10-15 consecutive video frames. Storing all 15 frames would flood the database with duplicate records. Our system implements a Spatio-Temporal Deduplication Buffer: 

// Distance check using Haversine formulation
function isDuplicateDefect(newDefect, recentDetections, spatialThresholdMeters = 5.0) {
  for (let record of recentDetections) {
    if (record.class === newDefect.class) {
      let dist = calculateHaversineDistance(record.lat, record.lon, newDefect.lat, newDefect.lon);
      if (dist < spatialThresholdMeters) {
        // Update existing record with higher confidence or larger box size
        record.confidence = Math.max(record.confidence, newDefect.confidence);
        record.observationCount += 1;
        return true; // Filtered duplicate
      }
    }
  }
  return false; // New unique distress event
}

This ensures municipal reports contain accurate physical defect counts rather than frame-rate artifacts.

4. Interpretable Visual Severity Scoring Matrix

Detection confidence measures the model's certainty that a defect exists, not how urgent the repair is. To prioritize repairs without requiring expensive LIDAR laser profilers, we derive an interpretable Visual Severity Index (VSI):

$$\text{VSI} = w_{\text{class}} \times \left( \frac{\text{Area}_{\text{bbox}}}{\text{Area}_{\text{road\_roi}}} \right) \times \left( 1 + \alpha \cdot \text{AspectPenalty} \right)$$

Where $w_{\text{class}}$ weights Potholes ($1.0$) and Alligator Cracking ($0.85$) higher than Longitudinal Cracks ($0.5$). This automatically maps each defect into actionable municipal buckets:

HIGH SEVERITY Potholes > 15cm width or alligator zones. Requires immediate cold-mix patch within 48h to prevent accidents.
MEDIUM SEVERITY Moderate cracking networks. Added to scheduled weekly asphalt milling/slurry seal routes.
LOW SEVERITY Early hairline transverse/longitudinal cracks. Flagged for preventive bituminous sealant.
